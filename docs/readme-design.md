## 目标与范围

将 GitHub 首页从机制说明和历史开发记录的堆叠，整理为面向首次访问者的项目介绍与使用入口。展示当前实现的通用游戏接入、个性化认知、原文可追溯记忆、仿真回放与验证范围。不修改 Python、前端、模型配置或游戏规则。

## 首页设计

1. 项目定位：通用游戏 NPC 引擎，解释认知核心与游戏自身 World/规则的边界。
2. 架构图：放在首页前部，以仓库相对路径引用 PNG，另提供可编辑 SVG；不依赖本地绝对路径、外部图床或运行服务。
3. 核心能力：稳定人格/动态关系、每 NPC 两库与三层逻辑记忆、证据约束反思、空间规划与认知调度、持久化与回放。
4. 快速开始：Python 3.10+、开发安装、默认离线的两个适配示例；可视化依赖单独说明。
5. 使用与扩展：两类样例、模型参数显式配置、持久化、接入新游戏的步骤和模块导航。
6. 验证边界：普通对话和通用游戏的记忆读取路径不同；结构化查询底座不等于任意自然语言历史问题规划；历史实验结果链接到带版本说明的评测记录。
