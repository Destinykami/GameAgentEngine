# 重构路线建议

状态：分模块实施中。实体、事件、世界库存储、NPC 公开边界、感知、包入口、自治决策、场景扩展、社交、动作执行和记忆内部职责已分别实现、验证并提交。后续顺序仍为建议，模块进度见 [实施记录](README.md#模块实施记录)。

已确认并实现：[决策蓝图](modules/decision.md) 采用共享流 + 全部可见对象关系面的原行为，不引入先选目标阶段。独立自治模块已完成提取与离线验证。

已确认并实现：[记忆蓝图](modules/memory.md) 采用绝对 `importance / 10`，行为修正和内部职责拆分分别提交；其他检索与维护规则保持兼容。历史在线评测已注明来自修正前实现。

## 目标

让修改某个机制时，可以从一份模块设计追踪到接口、状态、实现和验证。分离通用引擎、具体场景、展示及评测，使现有玩法和实验能够在边界调整后继续运行。

本轮重构建议优先保持行为兼容。关系阶段、信任随时间修复、idle 自治、多轮对话等新行为另立功能设计，避免混淆验证结论。

## 当前执行约束

用户已确认真实模型 API 不可达，当前只进行代码重构。实现与验收不依赖恢复端点，也不运行真实模型模拟、探针或在线实验。

使用离线模型替身固定输入输出，检查接口兼容、上下文组装、动作执行、状态变化、失败降级和持久化。保留现有模型调用及提示词语义；真实模型行为质量留待服务恢复后单独验证，不作为本次重构的完成条件。

## 推荐顺序

### 1. 固定契约与状态归属

先展开世界运行、决策、持久化、可视化四份蓝图，确定后续拆分要保护的接口：

- 单位与时间：小时、日边界、同一步的感知 / 执行时刻及浮点处理。
- 记忆作用域：共享流、单关系流、可见关系集合，明确查询与记录字段语义。
- 两条决策路径：事件反应与自治行动如何分工，哪些策略共享。
- 动作与结果：请求、校验、执行结果、失败、视觉事件及副作用的边界。
- 保存恢复：持久状态、可重建缓存、运行配置、钩子及未覆盖的恢复范围。
- 时间线：通用事件与快照、版本兼容、场景扩展字段和直播记录。

验收：每种状态有唯一责任模块；调用方能从设计确定可见数据、修改权限和失败行为；目标设计和现状差异逐项列明。

### 2. 建立配置与公开接口

补齐模型、世界、认知策略、实验与运行目录的配置设计；梳理并替换跨模块私有字段访问。先保留原有默认值与公开入口，迁移调用点后再决定是否移除兼容方式。

验收：示例和评测可以通过公开接口表达现有配置；配置变更能随运行记录保存；246 个离线测试继续通过。

### 3. 从 World 提取组件

建议按“数据类型与事件 → 感知 / 档位策略 → 行动执行 → 社交传播 → 持久化 → 循环编排”的顺序逐块迁移。组件数量与接口在世界蓝图中确定；不以行数作为拆分目标。

保留 `World` 作为兼容门面。每次提取只迁移一类职责，核对事件输出、记忆变化、行动顺序和错误降级语义。

验收：原有世界、动作、隔离、社交、持久化测试继续通过；有代表性的确定性轨迹在迁移前后保持等价。

### 4. 明确认知组件与 NPC 编排

依次展开记忆、反思、规划、对话与 NPC 蓝图。重点处理：MemoryStore 内策略与数据访问的边界，反思 / 固化触发，计划的多处状态，对话回流，以及缓存失效。

验收：上下文隔离、证据边界、幂等维护和缓存成本约束可逐项映射到现有验证；需要改变行为时单列变更及针对性验证。

### 5. 提取稻妻场景与运行器

将人物 / 地图 / 目标、动作效果、证据生成、说服裁决和结局条件从示例入口提取为场景职责；运行器处理时间推进、run 目录、快照、JSON / JSONL 和恢复策略。

验收：通用引擎通过接口调用场景规则；稻妻示例的组装、规则和产物链路通过离线模型替身验证；新场景无需改通用行动执行代码；运行产物有明确的覆盖与续跑策略。当前不要求运行真实稻妻模拟。

### 6. 整理回放与验证入口

在时间线契约稳定后，整理读取、直播跟随、播放与场景协调。逐步将原有设计资料合并进模块蓝图，旧文件保留历史记录或入口链接。

验收：时间线校验、前端构建及 E2E 通过；旧格式样本兼容策略有验证；模型、配置、调用量与评测结果能够对应到同一运行记录。

## 每一步的完成标准

1. 对应蓝图已经写明当前行为、目标变化和未决问题。
2. 变更规模有限，可以独立审查并回退。
3. 受影响的接口、调用方、状态归属和文档一并更新。
4. 运行适当验证，记录结果与未运行部分。纯文档修改检查引用与内容一致性即可。
5. 文件移动或接口整理后先确认兼容，再单独修改策略或行为。

## 验证层次

| 层次 | 解决什么问题 | 何时执行 |
|---|---|---|
| 离线测试 | 隔离、生命周期、幂等、动作契约、门控、保存恢复 | 相应代码变更后运行相关测试，阶段完成运行离线全集 |
| 确定性时间线 | 事件与快照是否在拆分后发生变化 | 世界 / 场景 / 数据契约迁移时 |
| 前端校验、构建与 E2E | 时间线、播放、交互、旧格式及直播是否可用 | 展示或跨端契约变更时 |
| 真实模型探针（当前暂停） | 模型接入、人格与关系行为是否仍满足要求 | 端点恢复后单独验证，不作为本次重构验收条件 |
| 三组在线实验（当前暂停） | 机制质量与推理成本是否发生变化 | 当前保留入口；后续提出新的效果主张时再执行 |

历史实验结果保留其原配置、模型与时间范围。结构重构通过测试不自动意味着所有历史效果已经重新验证。
