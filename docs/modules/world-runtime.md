# 世界循环与公开编排边界

状态：组件提取与场景所需公开模型查询已完成。核对日期：2026-10-23。

World 持有实体与认知注册表、空间索引、世界时钟、每日计划/固化锚点、动作效果及社交队列。实体、事件、感知、动作、社交、扩展和 SQLite 快照分别由对应模块负责；World 只编排它们，不引入具体场景。

NPC 通过 npc(name) 获取，自治绑定通过 register_agent 或 add_npc(autonomous=True) 注册。新增 agent_model(name) 返回已绑定模型或 None，语义与原注册表 get 相同；调用方不修改内部字典。场景、评测和离线生成器逐步迁移为公开注册/查询，原动作顺序与模型选择不变。

step、step_autonomous、execute_action、save/load/close 的时刻、先后顺序、每实体失败降级和跨库保存限制保持现有实现；具体行为由已完成的动作、感知、NPC 和持久化蓝图共同约束。不把世界循环拆为混入类，不增加新的事件总线或跨库事务。

验收使用离线世界/动作/持久化/隔离测试、场景对照及确定性时间线；真实模型与在线模拟不运行。
