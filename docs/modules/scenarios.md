# 稻妻场景与运行产物

状态：已实现，通过离线测试及原入口对照。核对日期：2026-10-23。

## 边界与布局

具体场景在 `game_agent/scenarios/inazuma/`：definition.py 保存人物、地图、目标及原运行参数；effects.py 保存证据生成、锻造、目击及注册钩子；judgment.py 保存将军裁决和原 JSON 容错；outcome.py 保存本步结局及回喂；setup.py 负责自治世界人物组装。脚本周剧情单独放 scripted.py，保留其显式故事顺序，不引入新的剧情 DSL。

`game_agent/runners/` 负责输出目录准备、JSON/JSONL 产物、自治运行循环及终端呈现。时间线 writer 不访问 NPC/模型/场景规则；runner 通过场景函数调用裁决，World 不导入场景。`examples/world_auto_sim.py` 与 world_sim.py 保留可执行入口和原路径默认值。测试直接导入场景实现，不再把示例作为库，也不保留旧示例函数代理。

World 新增 `agent_model(name)` 只读查询已注册模型，供场景证据生成；注册及调用顺序不变，场景不再读 `_agent_llms`。后续评测可通过独立公开 NPC 名称快照代替私有注册表。

## 不变式

- 现有地图坐标、人物属性/目标、证据容量、锻造增益及上限、思考/裁决提示词、周剧情事件与时刻保持原样。自治与脚本世界的不同人物数值不强行统一。
- 注册顺序仍 talk / attack / help / hide；生成证据只给 player，传原已收集证据，失败保守不新增；重复文本的历史反馈不变。help 与 hide 保留原判断，目击仍要求同一 Location 对象、存活玩家和原角色判断。
- 将军阵亡优先于说服判断；本步旅行者决策为直接 talk 将军才裁决，回复取原第一条匹配 conversation，不新增 success 过滤；裁决保留原 bool 转换。失败/拒绝保留原回喂文本及世界事件时机。
- 时间线元数据、开场、每步字段、null 门槛、视觉事件消费/清理顺序及终局标记不变。每行写完立即 flush，done 行后关闭直播文件，最终 timeline.json 使用原缩进和编码。
- 运行仍覆盖原 data/auto_sim、data/sim 目录及原直播路径，不新增续跑/恢复或默认路径策略。只有显式运行入口才清理该运行目录；导入不清理、不读写、不连接模型。离线验证只在临时目录调用入口，不动已有运行数据。
- 保留 World/NPC 保存顺序及逐步异常语义，不增加全流程事务、自动重试或额外模型调用。

## 验收

复用现有稻妻效果测试；新增裁决、结局和 writer 行协议/覆盖行为验证。以旧入口和离线模型工厂在临时目录运行，对比终端输出、模型调用、世界/NPC 状态、JSON/JSONL 与提前终止；核对脚本周剧情顺序和 16 步确定性时间线。导入隔离及独立安装不运行真实模型。

未决项：无。续跑、独立 run id、配置优先级或新结局均是功能变更，不纳入结构重构。

## 验证记录

395 个离线测试通过，新增 11 个裁决/结局/产物/组装用例和 12 个模块导入隔离用例。4 组自治离线配置（观望、裁决拒绝、说服成功、将军阵亡）的终端输出、模型调用、所有 SQLite 表及 JSON/JSONL 字节均与旧入口相同；完整脚本周剧情的输出、调用和所有数据库表相同，剧情操作 AST 一致；16 步确定性时间线相同。所有运行均使用替身模型和临时目录，没有运行真实模拟或访问模型端点。

独立 wheel 环境通过正式场景运行器和时间线产物检查；新增包由正式发行包包含。工作区差异检查通过。

+
+两个运行器以 finally 释放世界，自治运行器同时释放时间线文件。保存失败向外传播，不打印保存成功。正常结束时先发布 `data_dir/checkpoints` 完整检查点，再写成功结束标记/信息。检查点显式恢复至新运行目录，稻妻效果使用原 `register_scenario` 重绑定，不持久化模型或 Python 回调。实时数据库和时间线文件不提供跨文件原子提交，检查点是恢复进度的依据。
