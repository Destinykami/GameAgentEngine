# 评测场景、指标与运行入口

状态：已实现，通过原试验的离线对照。核对日期：2026-10-23。

## 职责与布局

`game_agent/evaluation/metrics.py` 负责记忆证据、过期召回、上下文冲突、用量汇总与分位数计算；不加载真实客户端或读取实验目录。artifacts.py 负责 JSON 和表格格式；runtime.py 负责显式连通性检查、模型/NPC 工厂与裁判问答，导入不连接端点。现有 probes.py 保留真实探针，当前不执行。

`evals/fixtures/` 拥有人格/信任/事件矩阵、记忆轨迹、调度人物及配置；`evals/baselines.py` 独立固定优先级基线。`evals/experiments/` 各自负责三类试验及汇总编排；顶层三个脚本保留原命令行入口，仅调用正式实现。路径默认值与时间戳目录在 evals/paths.py；移除 common.py / scenarios.py 聚合层，调用方显式依赖责任模块。

World 增加 npc_names() 返回插入顺序的独立名称元组，评测经 npc(name) 查询认知对象；自治模型继续公开注册，不读取或写入 `_npcs` / `_agent_llms` / `_agent_personas`。

## 保持的口径

- 四臂开关、轨迹顺序、人格/信任/事件矩阵、期望表、固定优先级规则和裁判提示词原样保留；不将裁判分数当人工校准结论。
- EGR 分母保持全部有效/失效关系反思，空证据不增加分子；缺失证据类型不算 grounded。保留原代码实际口径，不按旧注释改分母。
- stale_recall、上下文矛盾的检索参数、访问标记副作用、空集合返回结构及指标字段不变；不增加自动补键或异常修复。
- 用量按实例累加，不引入新的 latency 汇总；分位数保留原线性插值。调度事件在 25/49 时刻触发、当前时间表、N 扩展顺序及各配置预算不变。
- 保留原 CLI 参数解释（包括 decision 的 `--method=` 独立 token 加后继值规则）、默认目录覆盖、同秒目录复用、部分结果增量保存、JSON 默认转换及异常语义；不新增参数解析器或运行配置优先级。
- 依然只有显式真实评测入口才检查端点。此次验证通过注入替身工厂与裁判，不能产生新的真实模型质量或成本结论。

## 验收

离线检查指标边界、基线矩阵、工厂/裁判隔离、用量与分位数；用旧试验代码和替身模型对照轨迹、消融情境、调度配置、汇总输出和结果文件；保留各试验函数核心的 AST 对照。运行离线全集及独立导入检查，不运行真实评测或探针。

未决项：无。修正指标定义、CLI 语法或输出目录策略需单独设计，不混入本次重构。

## 验证记录

40 组完整记忆轨迹/消融臂、27 个决策场景（162 个事件决策）、6 组调度配置/N 的记录与原实现相同。三个冒烟控制器在替身工厂、离线裁判和固定时钟下的终端输出、runs/partial/metrics JSON 一致；13 个试验/控制器函数在归一公开注册表访问后 AST 一致。这些只是结构对照，没有执行在线评测，也不构成真实成本或质量结果。

410 个离线测试通过（8.02s），包括 13 个新增指标/基线/试验/CLI/公开查询用例和 2 个新增依赖隔离用例。三个顶层脚本已验证分发到各自试验入口；独立 wheel 安装的纯指标和格式检查通过，未加载 SQLite 或真实客户端。工作区差异检查通过。

## 2026-10-25 默认离线验收设计
+
+真实探针标记为 online，仅显式 `pytest --online` 才收集执行；默认跳过且不探测端点。离线测试在 socket/DNS 边界拦截外部连接，允许回环地址和替身；即使业务代码吞掉拦截异常，测试结束仍报告意外联网。该约束属于验收环境，不改变生产模型适配器。
+
+统一入口 `tools/check_project.py` 执行后端、前端测试/构建/时间线校验及离线 wheel 独立安装；浏览器用 `--e2e` 显式追加。构建依赖从本地缓存获取，缺依赖明确失败，不自动联网安装。核心层逆向依赖增加静态导入检查。暂不绑定未经指定的托管平台 CI。

实施验收：默认执行 453 个离线测试通过，6 个 online 探针直接跳过。独立 pytest 子进程确认在线夹具不会被调用、吞掉联网异常仍使测试失败、回环服务可用。统一验收入口实际跑通 10 个前端用例、构建、时间线校验及无网络 wheel 独立安装，检查点在安装包中往返成功；浏览器单独运行的 102 项断言通过。
