## 模块边界

`src/game_agent/world/actions.py` 负责输入规整、交互范围校验、移动 / 对话 / 攻击 / 逃跑 / 帮助 / 藏匿 / 等待的执行流程及行动事件输出。它依赖实体和事件契约，不导入 World、NPC、数据库或模型实现。

World 只为每次行动提供物理上下文和明确的服务回调；动作模块不接收整个 World，不访问注册表私有字段。决策选择、步进时序、重规划、社交传播规则和场景规则分别归其责任模块。

## 输入、状态与服务

- `ActionContext` 包含时钟、实体 / 区域映射、半径、威胁过滤器、传闻开关、交互动作集合和当前事件列表。映射与实体仍为原对象，不复制世界状态。
- `ActionServices` 提供认知查询、目标社交观察、传闻路由、效果执行和行为链记录等窄回调；具体组件由 World 组装。
- `ActionCognition` 只声明执行所需的 observe / speak，不暴露记忆库。
- `ActionExecutor` 无自身可变状态；每次执行显式接收上下文和服务，不长期缓存世界或模型依赖。
- World 保留 `execute_action` 及旧私有动作辅助方法作为兼容委托。

## 顺序与失败契约

保持输入字典复制与 utterance 规整、范围和存活校验。对话 / 攻击 / 帮助 / 藏匿先生成必要的认知事件，再提交物理状态或历史；说话者记忆回流继续尽力完成。

成功后按原顺序调用传播、场景效果、行为链和事件输出。服务异常仍交给原调用方处理，不增加跨模块回滚。随机伤害与逃跑择区沿用原算法和全局 random 序列。

缺失目标、非法动作、无威胁、失败事件、显示字符串、字段省略和默认等待保持原行为。World 的重规划仍根据原结果处理，本次不顺手修改该规则。
