# 原文混合检索、证据融合与对话接入

状态：存储、对话与评测均已实现并通过离线验收。日期：2026-11-06。
关联：[五类记忆](five-category-memory.md)、[原文与读取](tiered-memory.md)、[事件查询](memory-events.md)、[对话](dialogue.md)、[LongMemEval](longmemeval.md)。

## 1. 问题与目标

当前对话将原文 BM25、最多 128 条近期重要记忆的向量检索固定拼接。较早低重要性的经历可能在语义评分前消失，两个检索器不共享证据单位；关键词历史路由也会漏掉信息查询。本轮在原两库上实现统一 hybrid_retrieve，补齐原文片段向量持久化、RRF、来源归并、后置邻文与预算选择；对话和评测复用同一实现。

不增加记忆类别，不自动解析“那件事”或第 N 次，不改变旧 retrieve 的公式、反思语义或游戏默认近期窗口。不部署向量服务器或 reranker；提供可选的分数重排端口，不宣称真实召回质量已提升。

## 2. 契约与职责

- MemoryStore.hybrid_retrieve(query, scope, filters=EventQuery(), top_k=8, candidate_k=32, mode='hybrid', index_limit=64, neighbor_radius=0, reranker=None) 返回 HybridResult：hits 为原文片段字典元组，diagnostics 记录各路命中、索引完整性、降级原因与耗时。模式为 hybrid/bm25/dense；排序参数有界且严格校验。空问题不请求嵌入。
- scope 与 filters 在 SQL 候选生成前应用，参与者不扩大权限。未指定实例的混合检索仅使用实例为空的原档案，避免游戏秘密进入旧对话；显式实例仅查本局。时间上界同时检查 source/occurred/observed；非法锚点不降级为无条件查询。
- BM25 与 dense 共享 source_id + 片段位置。每路每来源只贡献一个最佳片段及一次排名投票；同一 source 多片段不刷票。不把摘要与原文作为独立事实重复计权。
- 原文证据排除 derived 以及 reflection/identity/episode/plan 类型的生成档案。主库有效 reflection/identity/episode 可作为提示：匹配后沿 evidence 与来源关联找原文，逐条重新检查范围与过滤；只给对应原文来源投一次提示票。循环、无来源、失效或越界证据不产生独立证据；有界展开。不把归档的旧失效信念当作新事实。
- RRF 默认 k=60；各路独立排名再融合，稳定同分。身份、时间及实例是硬范围，新近性和重要性不再作为原文语义召回前置门槛。显式结构化过滤可作为候选路线，但不通过相似度解释序号约束。
- 最终 hits 保留 category=raw_archive、usage=recall、来源/片段/证据性质、各路名次、融合分数及提示来源，便于审查。邻文在排序选择后展开，仅同来源会话和同范围；不将本轮来话用于证明历史。
- 邻文单独放在 HybridResult.neighbors，最多与 top_k 等量；先保留命中的核心证据，再由上下文预算选择邻文，不让邻文占掉更高排名命中的位置。

## 3. 持久向量与成本

新增档案内 chunk_vector 表，按 chunk_id、编码器标识及版本保存内容 hash、维度、归一化向量。标识包含编码器实现、维度和（HTTP 编码器的）服务地址/模型，绝不包含密钥；调用方可显式提升 embedding_version。自定义编码器变更权重需变更版本。主库格式不变，档案旧库增量建表，两库备份自动覆盖向量表。

原文追加仍不参与网络。index_archive(scope, limit=256) 显式分批补索引；查询默认限补 64 个可见片段，批内字符量受限。返回 remaining 与错误；未完成时必须标 dense_complete=false，不把部分向量覆盖说成全量召回。失败不删原文、不改派生 pending 队列，后续可重试；bm25 模式不调用编码器。向量错误仅降级词法路线并记录错误，SQL/权限/过滤错误直接传播。

第一版采用按可见范围流式精确扫描已索引向量，内存只保留有限 top 候选；延迟随语料增长，不宣称百万条性能或 ANN 已实现。模型/维度/版本变化不混用旧向量；片段索引重建清理对应向量，显式补建。不使用“最近 128 条”截断语义候选。

## 4. 对话与模型边界

明确空输入、寒暄及“不再提旧事”可只用背景；其他信息查询进行有界混合检索，不再依赖历史关键词白名单。普通寒暄保持零历史嵌入。背景仍来自原 working_memories，作为用途而非新增类别；按来源去重后受同一 3000 字符预算约束。source_refs 用于消除原文和派生观察重复占位；语义解释不伪装成独立原话。

对话使用显式当前对象+共享范围、now 之前的时间上界和无实例档案。替换 retrieve_important+search_archive 固定拼接为一个窄 hybrid_retrieve 端口；不为一次请求返回整库。模型仍接收原始用户问题，检索诊断放入 extra，不把改写或推断当作历史。可选 reranker 只返回有限候选的分数，不允许插入越界 ID；未配置时不产生额外模型请求。

对话原句超过核心检索的 4000 字符上限时，仅取前 4000 字符作为检索词并记录 query_truncated，原问题仍完整交给生成端；不因新增检索器上限使既有长输入直接失败。不声称截断后的检索保留所有尾部约束，精确条件仍须使用结构化接口。

## 5. 评测边界

LongMemEval 保留 memory/relevance/session 历史模式；新增 bm25/dense/hybrid 共用核心 hybrid_retrieve，按 turn 原文写档案，使用 source_id 映射回 turn，先来源归并再截 top-k。dense/hybrid 显式补全本题索引；任何失败或覆盖不全时报错，不能作为成功完整结果。per_question 记录检索诊断，CLI 支持三种模式。离线 fixture 对照验证管线；不把 HashEmbedder 数字解释为语义效果，不与历史真实 S500 直接比较。

## 6. 实施与验证

先设计，按记忆、对话、评测依赖顺序实施并各自验证提交；对话跨字段同步调整测试。记忆专项覆盖词面/无词面同义、早期低重要性、权限/未来/实例/过滤/锚点、同来源归并、原文与摘要不刷票、无证据摘要、持久向量重开复用/版本变化/维度错误/失败重试/索引重建、覆盖未完成诊断及只读访问水位。

对话覆盖寒暄、信息查询、隐含追问路由、预算、邻文、来源去重及失败隔离。评测比较 fixture 的 bm25/dense/hybrid，验证直接复用核心接口、严格完整性、原始 turn 聚合与输出诊断。最后运行全 Python 离线全集、独立 wheel/两库检查点及文档检查。真实端点、全 S500、生成质量、前端构建不属于本次离线验收。

## 7. 实施结果

记忆阶段（2026-11-06）：hybrid.py 维护轻量结果与 RRF；archive_retrieval.py 维护档案向量表、同范围的词法/流式向量/结构化候选；retrieval.py 负责索引批次、融合、证据提示、可选重排及诊断；MemoryStore 提供统一门面。新接口不修改旧 retrieve 评分和主库记录。

`test_hybrid_retrieval`、`test_memory_archive`、`test_memory_events`、`test_archive_checkpoints`、`test_module_dependencies` 共 **151 项通过**；另验证 HybridResult 公开导入不加载 SQLite。覆盖设计中的隔离、早期低重要性、人工同义向量、来源去重、有效/失效及旧库摘要导航、重启复用/版本/维度、失败和覆盖不全、损坏向量修复、后置邻文及重排契约。检查档案锁不在回查主库时持续持有。人工向量只验证管线，不代表真实语义质量。

对话阶段：使用 hybrid_retrieve 窄端口替代原固定拼接。当前时间上界用 nextafter 严格排除同轮输入；明确寒暄保持背景模式，其余信息查询检索。核心命中先于邻文进入预算，降级/覆盖诊断放入 extra.retrieval；来源去重只在完整来源已入选或内容实际重复时省略背景，不因仅命中一个片段就丢弃更完整观察。背景视图新增 source_refs，原主库记录格式保持。

对话、读取策略、模型、隐私、回流和档案专项 **53 项通过**（含长输入兼容回归）。

评测阶段：新增 bm25/dense/hybrid，原三种模式保留。新模式直接调用核心入口，严格要求完整索引；保存实际片段/偏移、排名与冷索引/查询/整题耗时，拒绝 resume 混用模式或 top-k。LongMemEval 新旧检索及 QA 单元测试 **29 项通过**；加入已索引向量的世界检查点恢复后相关 **32 项通过**。标准指标仍按 turn/session 计算，旧 QA reader 展开整条 turn，不等同于 NPC 的片段预算，本轮未跑 QA。

fixture 对照产物：`data/eval/longmemeval/hybrid-fixture-1d_tzfg9/`，三组各 2 题、HashEmbedder；所有逐题结果/summary/日志/比较文件非空、问题 ID 无重复、无降级，turn/session recall_all@5 均为 1.0。这只验证流程，不构成真实语义质量提升证据。

最终 Python 离线全集 **685 项通过、6 项真实端点测试跳过**（73.13 秒）；独立 wheel 源码与当前 src 一致，仓库外安装、正式导入、记忆隔离及两库世界检查点恢复通过。额外检查点断言确认已持久化片段向量随世界恢复，查询无需重新编码历史。52 份 Markdown 的 286 个本地链接、README Python 示例及 git diff --check 检查通过。
