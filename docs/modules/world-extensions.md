# 场景效果与行为链扩展

状态：与实现一致。核对日期：2026-10-23。

## 边界与状态

`src/game_agent/world/extensions.py` 管理动作效果注册、调用顺序、行为链规则和计数。仅依赖实体与事件契约，不导入 World、NPC、记忆库或模型适配。

每个 World 持有独立 `WorldExtensions`。扩展模块拥有效果映射和行为链水位；World 决定哪些成功行动需要记录，并负责把触发结果广播为世界事件。

## 接口与兼容

- `add_action_effect` 按动作追加回调；`run_effects` 按注册顺序调用。
- 回调签名仍为 `(world, actor, target, action, event)`，保留场景代码兼容。注册器只把调用方提供的上下文传给回调，不读取该上下文的属性，也不保存 World 引用。
- `add_chain_rule` 登记动作阈值与描述；`record_action(actor_id, action, target_id)` 仅更新本 actor 的计数，达到阈值返回事件描述，否则返回 None。
- World 的公开注册方法和可读写 `action_effects` 映射保持兼容。原私有链计数不再由 World 持有。

## 不变式

带目标行动会切断同一 actor 的其他动作 / 目标链；无注册规则的带目标行动只切断，不计数。触发后归零，不删除规则。失败动作不记录，由执行层在成功后调用。

钩子异常仍原样传播，不新增吞错或回滚；行为链不增加持久化。是否触发世界事件及事件地点仍由 World 决定。

## 验收

复用行为链、断链、失败不计数、场景效果和运行状态测试；增加新进程依赖隔离检查，运行离线全集及确定性时间线对比。不调用真实模型。

验证结果：256 个离线测试通过（3.47s）；新进程未加载世界 / NPC / 数据库或真实模型适配；16 步确定性时间线不变；`git diff --check` 通过。
