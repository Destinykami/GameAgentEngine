# Ninja Adventure 日式素材

来源: https://github.com/pixel-boy/NinjaAdventure (Ninja Adventure Asset Pack)
用途: 本地个人学习/演示。该仓库未附明确 LICENSE，按用户要求不再做许可证筛查；
      若要发布项目，请先替换或取得作者授权。

- `tileset_floor.png`：草地/土路/石地 autotile。
- `tileset_interior_floor.png`：和室木地板/石板/榻榻米。
- `tileset_village_abandoned.png`：和风房屋、石灯笼、苔藓树、木门、栅栏等。
- `../ninja-town.png`：由 `tools/build_ninja_town.py` 生成的 60×34 村庄底图。
- `*.png`（本目录根下）：从 village sheet 裁出的透明建筑/树/栅栏/岩石/倒木 Sprite。
- `torii_red.png` / `lantern_stone.png`：本项目补画的红色鸟居（含注连绳/纸垂）与石灯笼。
- `stone_steps.png` / `banner_red.png`：石阶与路边红色幟旗。
- 樱花飘落粒子由 `src/art/petals.ts` 在运行时生成，不占素材文件。
- `ninja-town.png` 中不包含建筑；房屋主城/治疗堂/眼狩署/神樱庭 1.5x、锻造坊 2x，
  仍参与 y-sort。红色鸟居/石灯笼为本项目补画的和风标志。
